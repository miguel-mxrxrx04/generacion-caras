# Generación de Caras con AE y VAE (CelebAMask-HQ 64x64)

Práctica académica de métodos generativos para la síntesis de rostros e interpolación en el espacio latente sin modelos preentrenados.

## Estructura del Proyecto
- `data/`: Conjunto de datos e imágenes externas de prueba.
- `notebooks/`: Cuadernos de experimentación y visualización.
- `src/`: Implementaciones modulares de arquitecturas, entrenamiento e inferencia.
- `weights/`: Checkpoints de los modelos entrenados.
